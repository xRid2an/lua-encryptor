Enkripsi teks/script Lua menggunakan Python dengan metode XOR dan Base64.

## ✨ Fitur

- 🔒 Enkripsi XOR sederhana
- 📦 Dukungan Base64 untuk teks panjang
- 🚀 Auto-generate kode Lua dengan fungsi decrypt
- 📁 Enkripsi batch file
- 🛡️ Obfuscation script Lua
